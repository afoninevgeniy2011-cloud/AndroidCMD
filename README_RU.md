# Android CMD Simulator

Это учебная **имитация** внешнего вида Windows CMD для Android. Она не запускает Windows и не выполняет команды Windows над файлами телефона. `dir /s` выводит большой, но ограниченный демонстрационный список, чтобы приложение не зависало и не заполняло память бесконечно.

## Сборка APK в Android Studio

1. Установите Android Studio с официального сайта Android Developers.
2. Распакуйте архив `AndroidCMD.zip`.
3. В Android Studio выберите **Open** и укажите распакованную папку `AndroidCMD`.
4. Дождитесь окончания Gradle Sync. При запросе установите Android SDK Platform 35.
5. Для создания APK откройте **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. После сборки нажмите **locate** в уведомлении Android Studio. APK обычно находится здесь:
   `app/build/outputs/apk/debug/app-debug.apk`
7. Перенесите APK на телефон и откройте его. При необходимости разрешите установку приложений из этого источника.

## Команды

- `color 0a` — зелёный текст на чёрном фоне.
- `dir` — демонстрационный список папок.
- `dir /s` — длинный прокручиваемый демонстрационный вывод.
- `cls` — очистить экран.
- `help` — список команд.
- `cd`, `cd имя`, `tree`, `ver`, `date`, `time`, `echo текст`, `whoami`.

## Примечания

- Требуется Android Studio с JDK 17 (обычно поставляется вместе с Android Studio).
- Проект не включает Gradle Wrapper; Android Studio создаст/скачает нужные компоненты при первой синхронизации.
- Для реального Linux shell на Android нужен другой режим/приложение. Этот проект специально имитирует CMD.
